# Forbes Analytics

Учебный проект УРФУ
Веб-приложение для анализа данных Forbes с возможностью визуализации и управления данными.

## Описание

Приложение представляет собой интерактивную систему для работы с данными Forbes, включающую:
- Таблицу с данными о лидерах
- Возможность сортировки по различным параметрам
- Поиск по таблице
- Добавление, редактирование и удаление записей
- Визуализацию данных в виде графиков
- Адаптивный дизайн

## Использованные технологии

### Backend
- **Spring Boot** - фреймворк для создания веб-приложений
- **PostgreSQL** - система управления базами данных
- **JDBC** - для работы с базой данных
- **Thymeleaf** - шаблонизатор для HTML

### Frontend
- **HTML5** - структура веб-страниц
- **CSS3** - стилизация и анимации
  - Flexbox и Grid для верстки
  - CSS transitions для анимаций
  - Media queries для адаптивности
- **JavaScript** - клиентская логика
- **Chart.js** - библиотека для создания интерактивных графиков

### Графики
В проекте используются следующие типы графиков из библиотеки Chart.js:
1. **Столбчатая диаграмма** (Bar Chart)
   - Для отображения топ-10 лидеров по состоянию
   - Для возрастного распределения
2. **Круговая диаграмма** (Pie Chart)
   - Для распределения по странам
3. **Кольцевая диаграмма** (Doughnut Chart)
   - Для распределения по индустриям

### Особенности реализации
- Реализована сортировка по всем полям таблицы
- Добавлен поиск по всем полям в реальном времени
- Реализовано модальное окно для редактирования записей
- Добавлена валидация форм
- Реализован адаптивный дизайн для мобильных устройств
- Использованы современные эффекты и анимации

## Установка и запуск

1. Клонируйте репозиторий
2. Создайте базу данных PostgreSQL
3. Настройте подключение к базе данных в `application.properties`
4. Запустите приложение через Maven:
```bash
mvn spring-boot:run
```
5. Откройте браузер и перейдите по адресу `http://localhost:8080/top`

## Структура базы данных

Таблица `top` содержит следующие поля:
- `Rank` - ранг в списке
- `Name` - имя лидера
- `Net Worth` - состояние
- `Age` - возраст
- `Country` - страна
- `Industry` - индустрия
- `Score` - компания
